# Examples

Fictional projects that show what good output looks like. The AI reads these to copy the shape, the plain wording and the level of restraint, not the content. Every example follows the layout in `../references/spec-template.md`: a short version first, plain English, one running number, and technical details last. Names, files and numbers are made up.

| File | Mode | Shows |
|---|---|---|
| `first-time-setup.md` | 1. First-time setup | A small starter set with reasons, the foundation, and rejected candidates |
| `onboarding-revamp.md` | 3. Revamp | A 4-page onboarding: keep, change, remove, and the new minimal set |
| `audit-report.md` | 4. Cleanup | Certain vs judgment findings, limits, and a Mixpanel-side checklist |
| `pr-review.md` | 6. Review a change | A short ranked review of a diff |

Mode 2 (new feature) uses the same structure as the first two, with a REUSE section. Mode 5 (troubleshoot) uses the troubleshooting template in `../references/spec-template.md`.
