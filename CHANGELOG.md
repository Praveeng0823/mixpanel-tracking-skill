# Changelog

## 0.1.0
First release.
- Six modes: first-time setup, new feature, revamp of an existing area, cleanup audit, troubleshooting, and change review.
- Plain-English replies for product managers and founders: short version first, one running number, technical details last.
- Reasoning rules that keep tracking small: decision, implied, difference and removal tests, plus a list of what was left out.
- Hard stop for approval before any code changes.
- Mixpanel rules with sources: identity, naming, autocapture, limits, privacy and regions.
- Script that finds tracking calls, six sample apps and pass/fail checklists.
- Follows the open Agent Skills format, with install folders for Claude Code, Cursor and Codex, and a Cursor plugin manifest.
- Tested in Claude Code only.
